# Task 1: Development Environment Setup

## Overview

This task focuses on preparing a complete development environment required for full-stack web development. The setup includes installing essential development tools, configuring version control, setting up a database environment, and verifying that all required tools are working properly.

This setup will be used as the foundation for building backend APIs and frontend applications during the Codveda Technologies Full-Stack Development Internship.

The main objectives of this task are:

## Basic Git Commands Practiced

Initialize repository:

```bash
git init
```

Check file status:

```bash
git status
```

Add files:

```bash
git add .
```

Commit changes:

```bash
git commit -m "Initial commit"
```

Push code to GitHub:

```bash
git push origin main
```
